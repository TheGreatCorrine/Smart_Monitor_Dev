🔗 Available API Endpoints

Configuration Management:

  • GET /api/config/labels - Get Label Configuration
  • POST /api/config/labels - Save Label Selection
  • GET /api/config/labels/load - Load Label Selection
  • GET /api/config/rules - Get Rule Configuration
  • GET /api/config/channels - Get Channel Configuration

File Management:

  • GET /api/file/list - List Data Files
  • GET /api/file/info/<filename> - Get File Information
  • POST /api/file/validate - Validate File Path
  • POST /api/file/infer-workstation - Auto-infer Workstation ID

Monitoring Management:

  • POST /api/monitor/start - Start Monitoring
  • POST /api/monitor/simulation - Start Simulation
  • POST /api/monitor/stop - Stop Monitoring
  • GET /api/monitor/status - Get Monitoring Status

System Information:

  • GET /api/system/info - Get System Information
  • GET /api/system/health - Get System Health Status

Web Status:

  • GET /api/web/status - Get Web Application Status
  • POST /api/web/reset - Reset Web Session
